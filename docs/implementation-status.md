## Accuracy targets: which number answers which SRS requirement

The SRS §16 "Success Metrics" table (`data/TruthLens_AI_Fake_News_Deepfake_Detection_SRS.docx`) sets three
different quality targets, and only one of them is "> 80 % accuracy" for text-free reasons:

| SRS §16 area | verbatim target | applies to |
|---|---|---|
| Text Classification | validation/test accuracy **above 85 %** | WELFake Real/Fake classification |
| Claim Retrieval | **top-5** retrieval accuracy **above 80 %** on a manually defined evaluation set | FEVER evidence retrieval |
| Image Detection | validation/test accuracy **above 80 %** on the selected FaceForensics++ subset | manipulation detection |

There is **no 80 % text-accuracy target** — an earlier line in these docs attributed "> 80 %" (and later "> 90 %")
to text; both were wrong and now quote the actual 85 %. For every model, three measures are kept separate and must
never be substituted for one another:

| measure | what it counts | who uses it |
|---|---|---|
| **overall accuracy** | correct verdicts with every UNCERTAIN counted as a miss, over the full held-out set | **the only figure comparable to the SRS targets** |
| **accepted-prediction accuracy** | correct among definite verdicts only (UNCERTAIN excluded) | reports reliability *where the system speaks* |
| **coverage** | share of rows reaching a definite verdict | reports selectivity, never accuracy |

Image: overall **70.07 %** (2,943/4,200) on the held-out **test** split → target NOT MET; accepted-prediction 79.16 % (2,943/3,718) and coverage
88.52 % are *not* overall accuracy. **Do not read the 72.07 % (3,027/4,200) reported by the 2026-10-16 image stage as an
improvement over 70.07 %** — it is the same checkpoint on the *validation* split, a different 4,200-frame set of the same size,
and that stage promoted no candidate, so the test split was never reopened. Text: overall 99.15 % (6,314/6,368) → 85 % target met. Retrieval: top-5 gold
recall **27.5 %** (55/200) on the deployed index → 80 % target NOT MET. Two lawfully built candidate indices were

80 %, ceiling 79.5 %), and round 2 crosses the target at **87.0 %** (174/200) merged. Neither was deployed and the
target is **not** recorded as met: round 2's gain is per-claim targeting (removing the pages the query's own text
matched drops its recall@5 from 176/200 to 2/200, so shipping the file delivers none of it), the online form costs
0.21–6.13 s per claim measured on a service already at 7.97 s against a 5 s text budget, and the selector rules were

  disjoint remainder was **not opened**, and deployed recall@5 remains **258/400 = 64.5 %** (verdict route 0.275).

- **FEVER evidence verification** uses a retrieval corpus that is not the full Wikipedia corpus; single-passage NLI does not handle all multi-hop claims; evaluation metrics (held-out `accuracy` ≈ 0.41) are below a production benchmark target and are documented as such. Until 2026-10-14 the verdict scanned the whole retrieved pool and took the highest-clearing NLI candidate with no test that the passage is about the claim, so a lexically-similar *neighbouring* passage could outrank the correct one (demonstrated: "The Matrix is a 1999 science fiction film" is entailed by `The_Matrix#0` at 0.997 yet was reported REFUTED because `The_Matrix_Revolutions#0` contradicts "1999" at 0.999). That selection step is now repaired: a deterministic claim-addressing gate (`ai-service/app.py` `claim_addresses` / `gate_and_select`) requires every candidate to name the claim's subject, and requires a refutation to address the claim's assertion as well; passages that fail are returned as inconclusive with the reason, never as evidence. The gate is rule-based, so model weights, exported thresholds, class mapping, corpus and iteration are unchanged. Remaining model limitations, measured on 299 held-out FEVER claims: REFUTED precision 0.440 with 22 correct and 28 wrong among the 50 emitted refutations (the contradiction channel keeps firing at ≈0.99 on unrelated facts about the same subject), morphological rather than semantic vocabulary matching, and annotated gold-evidence retrieval of only **55/200 = 27.5 % at top 5** (the 58/200 = 29.0 % figure is the top-**10** diagnostic, not the top-5 result; see the FEVER top-5 row above) — of the 187 claims with no gate-passing candidate, 108 never retrieve the gold page, 68 have no FEVER gold evidence by construction, 10 are gate rejections of a retrieved, NLI-clearing gold sentence and 1 fails a pre-gate score floor, which is what raises abstention from 0.582 to 0.729.
