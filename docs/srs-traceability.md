Dataset note: WELFake replaced the SRS FakeNewsNet text-classification source. FEVER was added for evidence verification. LIAR remains experimental related-claim classification, not verification. Image scope is FaceForensics++ frames, not arbitrary internet images or video/audio.

Guest submission is an explicit gap. The current policy requires login for private analysis operations.
